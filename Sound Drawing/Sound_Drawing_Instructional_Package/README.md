# Sound Drawing Instructional Package

- Sound_Drawing_Complete_Recreation_Guide.md is the main educational artifact (~15k words).
- examples/ includes a verified 48 kHz two-channel WAV, an FFmpeg XY preview, and still.
- video_inspection/ contains frame overview contact sheets and additional examined source stills from the four supplied MOV recordings.

The guide explicitly distinguishes source observations from supplemental implementation advice and states audio transcription limitations. Source video files themselves are not duplicated in this ZIP.
