# Developer system logs

System-log forwarding to notification NoticeCards has been removed for all users,
including developers and administrators. Notifications no longer subscribe to
`main.log`, retain global developer events, or display raw log entries.
Normal workspace notifications and user-facing error notices remain available.

View system/debug information in **Settings → Developer → Logging**. Persistent
logging, native log reading/watching, log parsing and the Developer access rules
remain in place for that dedicated section.
