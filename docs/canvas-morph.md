# CANVAS MORPH

Preset ID `canvas-morph`, renderer `morph`, nested settings version 1 (CANVAS schema 22). A direct-source visual processor inspired by the supplied Photism recording, independently implemented using the existing WebGL2 lifecycle. No new dependencies or separate audio analyzer.

## Operation and source ownership

Select CANVAS → Morph. Use Source → MORPH Source to select Active Media, a named Media Pool (rotates on qualified four-bar positions), or Default Visual. Clear Source returns to a local built-in SVG without deleting or modifying the media library. Selecting media manually or pasting an image returns to Active Media. Missing/empty pools fall back to the default visual. Clipboard uploads use the canonical media upload and signing path; authentication/storage configuration and clipboard permission may be required. The standard decoder accepts supported PNG, SVG, JPG and video media. Authored compositions, layer effects and active saved shows retain their output ownership; use single-source mode to perform MORPH. The pool option is independent of generic multilayer Pool Automation.

## Design and performance

Form: mode, transformation, identity, reconstruction, complexity, depth, mode-specific dot/tunnel controls. Motion: speed, turbulence, direction, rotation, recovery. Material & Mood: original colors or selectable palette, brightness, feedback, bloom, quality, seed. Audio & Choreography: reaction, impact, pattern, Pattern Change, Trigger, BPM Sync, transition duration, Auto Performance. Identity at 100%, reconstruction at 100%, or amount zero is an exact clean-source bypass. Identity is a deformation constraint, not a measured legibility percentage.

Three algorithms: SMEAR uses multi-step curl advection, domain warp and directional wakes; HALFTONE uses an inverse-warped source-colored cell lattice with analytical shading; DROSTE uses blended periodic log-polar bands and angular repetition. Mode changes crossfade source-derived results, rather than abruptly swapping shaders. Two full-size history targets plus two quarter-resolution bloom targets, no bloom feedback. Resource bounds and disposal use existing direct WebGL lifecycle. History clears on source/geometry/mode/transport changes or resize. Source color is default; optional palettes are luminance-based.

Eight authored patterns: IMPACT (short hits), UNDERTOW (sustained flow), REBIRTH (periodic reconstruction), OVERLOAD (escalating energy/trails), DESCENT (recursive tunnel), FRACTURED (spatial tears and recovery), BREATHING (readability), METAMORPHOSIS (three-mode four-bar progression). Pattern Change and Auto Performance are exclusive; manual selection does not mutate the pattern during performance. Auto chooses temporary section-aware patterns using the canonical Shared Performance Context; qualified beats/phrases/drops drive the selected triggers. Manual mode is authoritative unless DESCENT or METAMORPHOSIS is selected. Pattern Change advances once per qualified event. BPM Sync uses canonical beat position, with ambient motion fallback. No new beat detector. Transport resets clear motion history and envelopes; pause holds the source and clock.

## Acceptance

Run `npm ci`, `npm run typecheck`, `npx vitest run src/components/vyzualz/react/renderers/morph/Morph.test.ts`, and `DRMVYZ_SHOW_DIRECTOR_WEBGL_VISUAL=1 DRMVYZ_WEBGL_HEADLESS=1 npx playwright test src/test/e2e/canvasMorphWebGL.spec.ts --project=chromium`. The browser test bundles the actual renderer and checks distinct modes, motion, bloom, reconstruction, and resize with pixel readback. In the full app validate all three modes using a transparent logo, opaque image, SVG, and video; paste and clear; pool switching; all eight patterns; manual/trigger/auto authority; pause/seek/loop; preset reload, capture, cast, and authored show isolation.

Reference: the 14.4-second recording shows recognizable lettering at ~2–3s, intense source-colored liquid at ~4–6s and ~9–11s, a shaded dot lattice at ~6–8s (apparently different source), and tight red/orange radial repetition at ~12–14s. The reference audio is silent. Exact proprietary shader/pixel and musical timing parity cannot be claimed. This version extends the earlier V2 rendering foundation. The current authoring environment cannot install npm dependencies (offline cache missing) or launch Electron; standalone controller assertions passed. The updated shader programs compiled and linked through native ANGLE OpenGL ES 3.0; the actual TypeScript renderer was also transpiled and run in a standalone Chromium WebGL2 context under Xvfb (with Vite’s development flag replaced by false in the harness). Pixel tests using an isolated raster from the recording passed for all three modes, motion, bloom, clean recovery, mode blending and resizing. These are standalone renderer checks, not a complete Electron/UI launch. The checked-in Playwright and Vitest suites, full typecheck, capture/cast and live in-application acceptance remain required.
