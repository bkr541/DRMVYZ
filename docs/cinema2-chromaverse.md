# Cinema 2.0 CHROMAVERSE review pack

Ten supplied GLBs become native, separately keyed SYSTEM presets, available to all users without individual ownership grants. Their renderer acceptance role remains reference until production visual acceptance; this is independent of catalog scope. Apply the binary Git patch, then run `supabase/migrations/0064_chromaverse_preset_pack.sql` in the target database (or `supabase db push` after reviewing pending migrations). The migration registers system scope, creates the CHROMAVERSE admin catalog pack and attaches all ten presets. Catalog publication metadata starts at designing; no marketplace release is created. The catalog pack has no artwork yet; upload via the Admin Console. The normal SYSTEM fallback applies while the catalog loads or is offline.

## Architecture

`ChromaverseDomain` defines the individual profiles, pattern names, spatial coefficients, palette and parameter labels. `Cinema2ChromaversePresets` builds ten independent manifests with stable IDs, canonical Design parents, eight palette recipes, shared pattern policy, eleven trigger options, 22 audio/director routes, and Mood Conductor drives. `Cinema2ChromaverseNativeModule` handles transport, event deduplication, pattern transitions, shared beat timing, build/drop overrides and lifecycle. `ChromaverseChoreography` only authors model poses and surface values through the existing `Cinema2ThreeSceneBridge.modelController` hook. The shared bridge exclusively owns draw execution, framebuffer binding, camera, lights, environment and shader warm-up. Clips use `Cinema2ThreeAnimationController`, repeated elements use `Cinema2InstancedBatch`, and the prepared scene is a skeleton-safe clone. No pack-specific rendering component remains. STARFIELD WARP and MAGIC WARP batch repeated source geometry via GPU instances. ALTER EGO uses skeleton-safe cloning and preserves original morph targets. TEMPLE OF LIGHT uses native motion without an authored clip.

Audio reactivity is an authored strength; Auto Performance selects effective pattern policy and mood modulation without rewriting saved controls. Palette remains user-authoritative. The pattern domain uses ten spatial-program families, source-specific coefficient sets, and rendering transforms; further artistic differentiation must be evaluated in the live canvas. Effects include HDR bloom, atmosphere, cinematic finish/aberration, surface opacity, emissive tint and short motion trails. The shared camera provides aspect-aware projection, bounded paths, motion safety and tempo controls. The runtime asset copy is not a replacement for the original GLB archive.

## Assets and packaging

Source license CC BY 4.0 and author/source URL are in each asset record and the generated attribution list. Runtime copies use exact buffer/accessor deduplication, texture downsampling (maximum 512 or 1024 pixels depending on source), and animation keyframe resampling (approximately 8 or 15 samples/second for densely baked tracks; short or sparse tracks preserved). The 10 originals were 533 MB; optimized copies add about 119 MiB to the existing installer assets. No remote hosting dependency is introduced. `budgets.json` increases the aggregate installer cap to 300 MiB and permits only ALTER EGO and MAGIC WARP to exceed the default 16 MiB individual file cap. This is an explicit distribution tradeoff, not a GPU performance certification. Morph memory in particular needs GPU profiling: the existing asset checker estimates base geometry and textures but not the full morph texture upload. Runtime reports an additional estimate for unique morph attributes. The original TIME TUNNEL includes a photosensitivity warning; default motion is reduced, rapid flash accents suppressed, and original optical patterns may still be unsafe for susceptible viewers. Do not promote before luminance review.

## Validation / remaining review

Run `npm run assets:check`, `npm run test:assets`, `npx vitest run src/components/vyzualz/cinema2/__tests__/Cinema2ChromaversePreset.test.ts`, and `npm run typecheck`. Check each GLB and every pattern in Electron's real production canvas, including animation seams, morph textures, native effects, all camera presets and aspect ratios, manual/Auto Performance authority, seeks, silence, and playback/cast/record. Test renderer GPU/memory and visual fidelity on target Macs before shipping. These are reference-role implementations, not a guarantee of 60fps or completed human visual acceptance. Catalog thumbnails and pack artwork require capture/approval. The on-demand native thumbnail capture now waits for actual bridge readiness and visible model surfaces. To publish all ten real WebP thumbnails, run the Vite server (`npm run dev`) and, in a second terminal, `node scripts/generate-preset-artwork.mjs --chromaverse`. Commit the ten output WebPs under `public/preset-artwork/` after visual review. Do not substitute placeholder artwork or mark these presets production-ready until the live acceptance gate passes. Migration 0064 is unchanged: it registers system catalog metadata and pack membership only, and can remain unapplied while local rendering is validated. Separate per-parameter controls for all proposed concept details are not claimed: the first implementation exposes source-labeled structure/motion controls and common optical controls, with additional specialized behavior to be tuned during visual review.
