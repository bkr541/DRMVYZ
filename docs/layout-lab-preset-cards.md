# Layout Lab preset cards

The stable Preset cards tab (`layout-lab-tab-02`) contains thirteen comparison rows. Renaming the tab preserves its content. Rows 01–10 retain the original card and Performance Pad studies at the production 148.5 × 69px tile size. Row 01 centers its floating title over the artwork with a subtle text shadow. Caption bands in rows 02–03 reserve enough space for two title lines.

Every row compares **Reactor**, **Ancient Machine**, **CANOPY** and **Electric Storm**. The second and fourth slots use current production Cinema 2.0 presets to expose two-line title behavior. Long names wrap at word boundaries inside a consistent title measure; the full production name remains visible. Images are the production-renderer frames in `public/preset-artwork/`, generated by `scripts/generate-preset-artwork.mjs`.

Three independent asset-browser studies follow the original ten:

- **11 Asset library:** 16:9 preview above a solid caption area, two-line title space, engine metadata and a separate favorite action.
- **12 Compact library:** a thumbnail beside stacked title and metadata for dense browsing.
- **13 Immersive gallery:** full-card preview, an anchored contrast scrim, title, engine badge and floating favorite action.

These new studies follow the preview/title/metadata/secondary-action anatomy described in [Adobe Spectrum's card guidance](https://spectrum.adobe.com/page/cards/), using the application's shared typography roles and focus colors. Their layout and surface rules are independent of the Performance Pad treatments.

Selection and favorites are independent per row and remain local to the study. No engine, audio or cast runtime is started. Card actions support keyboard focus and activation. All four cards stay in each comparison row; the surrounding Layout Lab canvas supports scrolling at narrow widths.

## Engine dropdown studies (tab 3, default name "Engine dropdown")

Five rows, each showing every production engine choice (`REACT_ENGINE_IDS`) as an option card at the exact production size: 330 × 84 px (the 354 px rail less its 12 px inset; card height 96 px less that inset), 1 px neutral border, 4 px corner, 6 px 12 px 4 px padding, with the production card contents (blueprint artwork, pixel label for PixGrid) and the shared engine eyebrow/label type roles. Rows stay inside the application's look (dark panel surfaces, the cyan primary, hairline borders) and differ in structure: Accent rail (left rail, small blueprint at right, index), Icon tile (framed blueprint chip, two-line text), Spotlight wash (edge-to-edge artwork under a primary wash, title at the foot), Drafting grid (full grid field with corner ticks) and Recessed well (darker inset surface, ghosted artwork, underline that fills on selection). Selection is local to a row and never changes the real engine. Sound Drawing XY has no blueprint artwork in production, so its art slot is empty in every row. Source: `layoutLab/EngineDropdownStudies.tsx` and `engineDropdownStudies.css`.

## Navigation icon studies (tab 4, default name "Nav bar icons")

Twenty rows of custom SVG path icons for the left navigation, each with the six destinations: Performance Pads, Presets Manager, Show Manager, Lyric Manager, Media Manager and Notifications. Every glyph is drawn on the navigation's 32 grid in `currentColor` plus one `--llni-accent` shape (the convention production's nav already uses), and each cell shows the artwork large and as the real collapsed-sidebar item (72 px column, 28 px icon, 3 px active edge, active glow). The systems differ in construction, not just stroke: Hairline duotone, Bold line, Solid glyph, Tinted fill, Technical cut, Plotter dash, Offset depth, Badge tile, Medallion and LED matrix, then five inspired by reference icon sets: Hex fragments (broken hexagon frames with accent segments), Offset duotone (slate outline with the accent shifted off the edge), Fade trail (strokes fading along their length with a ghost echo), Dark inlay (light outline around a dark tinted interior) and Flat geometry (stroke-free circles, bars and triangles). The last five follow a content brief: Pad console, Neon tube, Spec sheet, Solid stamp and Chip tags. Their Performance Pads follow production's pad surface (dark tile, 1px border, colour line, lit hit state), Presets show configuration (sliders, knobs, toggles, parameter tables), Show combines DJ lighting fixtures and beams with a timeline, Lyrics combine a mic, lyric lines and a note, and Media shows image, video, audio and font types. After the first review, the 16 icons marked Keep were frozen and the other 104 were redrawn from scratch to the content brief (production-pad surface, configuration, DJ lighting plus timeline, mic with lyrics and a note, several media types); keep ids are unchanged, so the saved Keep marks still apply to the same 16 icons. Row 09 (Medallion) is now the production left navigation: `src/components/vyzualz/navMedallionIcons.tsx` (`NavMedallionIcon`) draws Performance Manager, Preset Manager, Show Manager, Lyric Manager and Media Manager in `VyzualzSidebar`, and the lab row renders the same artwork. React (home) and Notifications keep their existing icons. Below the twenty rows, a Performance Pads options row (`NAV_PAD_OPTIONS`) shows five candidate symbols inside the production Medallion ring at the production size, each with its own Keep checkbox, followed by a React options row (`NAV_REACT_OPTIONS`) with five candidate symbols for the React (home) item, then two more React rows drawn from what React is in the app: a live-stage row (monitor, stage over pads, output cast, engine stack, stage over dock) and an audio-reaction row (wave to shape, beat burst, spectrum frame, scope dial, live indicator), then two rows from the engine functionality in `reactEngineCatalog.ts`: engine marks (Cinema 2.0, Sound Drawing, CANVAS, LaserDMX, PixGrid) and the engine system (hub of seven, switcher, selector, one in many looks, rack). Each icon has a Keep checkbox (saved in the popup) to mark which to keep; unchecked ones are to be redone. The icon library is `layoutLab/navIconSystems.tsx` (`NavIconArtwork`); the row styling is `navIconStudies.css`.
