The compiled reviewed manifest remains authoritative. The reviewed inventory contains these seven media-capable entries; no supported formats or slots have been changed.

| Preset | Slot | Formats | Authored checkpoint / treatment |
| --- | --- | --- | --- |
| Corridor | corridor-panel-media | image, video, SVG | Dedicated/hybrid panel content; native fixtures remain active; source exposure independent of fixture intensity, as in SYS-05. Wrapping banks may occupy all nine coarse screen regions. |

Vacancy, Electric Storm and Reactor also declare slots outside the reviewed inventory; this patch does not enlarge QA-02's reviewed scope. The source panel resolves library metadata (including SVG role and proxy preference) into a canonical source; the production slot decoder loads an image/SVG or video and uploads straight-alpha RGBA without Y-flip. Individual modules own UV orientation, aspect, composition and intentional exposure; render graph finishing remains enabled. SYS-05 already separated Corridor and Overdrive source exposure. No newly demonstrated renderer defect was established in this environment; no material, camera, choreography, finishing or palette defaults were changed. The library source conversion helper is extracted unchanged and re-exported from its original path; the browser decoder is exported for the test-only delegating probe. SVG is decoded as a browser image by the actual slot loader; a separate uploaded SVG proxy-generation workflow is not covered.

## New checks

The prior video was a recorded canvas repeatedly painting white in an already-white quadrant. It could pass without ever displaying a different frame. The prior SVG and video checks also omitted matched removal. The replacement test fixture is a locally generated VP9 WebM (320x180, two distinctly colored one-second segments, fiducials and T0/T1 labels). The PNG chart, alpha chart (transparent cutout and half-alpha white), tall chart and SVG are generated locally, without network assets. The source mapper and native browser decoder are used, not ready textures. A delegating test probe pins the actual video element at 0.2 and 1.2 s while the music/scene clock remains unchanged. It also releases the pin to exercise the production transport pause, resume and loop callbacks. No test hook is enabled outside the release harness.

The shared runner performs independent deterministic off/A/A/on/removed captures for each supported format/variant at high, medium and low quality at the breakdown checkpoint. Chart idle/build/drop observations are recorded separately at high quality because the authored choreography may conceal content intentionally. These staged observations use the original stage energy/event sequence rather than the fixed controlled-event fixture. A hidden-source control, replacement and a four-entry pool selection through the actual native pool facet are included. Pool requests demonstrate progression through the resolver; they are not proof that every resolved feed reached a visible panel. The pool source is a local test implementation of the production interface, not a persisted workspace or signing test. All capture records retain phase, quality, settings, ROI, source identity, playback time, decoded samples, thresholds and result. The runner has an increased 30-minute per-preset watchdog for the larger matrix. No test was disabled to make the release pass.

`media-fidelity-evidence.mjs` checks the decoder against independent source-coordinate fiducials and expected alpha; negative controls cover wrong hue, wrong orientation, dimensions, destroyed alpha, hidden final-frame content, stretched projection and static video. Final-frame temporal evidence compares different video timestamps at matched scene time against same-timestamp A/A noise. The existing visibility and fallback evaluator still measures final composited pixels, not fragment-only output. Coarse chromatic ROIs alone cannot establish aspect, exact orientation, readable text, halo or alpha composition. `projectedMediaEvidence` requires independently calibrated screen-space regions. Missing masks explicitly leave `media-projected-fidelity` incomplete rather than pass on a hue count. No masks were calibrated without a functioning browser.

To supply reviewed masks after inspecting the authored geometry, run the shared release command with `--media-masks /absolute/path/to/masks.json`. JSON keys are `preset/variant/quality/breakdown` (e.g. `everywhere/alpha/high/breakdown`); each value contains `width`, `height` and `regions`, at the captured viewport size. Each region has a descriptive `id`, integer pixel `x`, `y`, `width`, `height` and either expected display-referred `expected: [r,g,b]` or `background: true` for an unchanged transparent/background region; `tolerance` is an absolute byte tolerance (default 40, maximum 60). Calibrate from intended projection, fit, source color and authored finishing, not by selecting colors from the actual result. Include distinct interior fiducials, transparent holes, semitransparent and edge areas, and expected uncovered regions. Four or more independent regions are needed; at least 80% of pixels per region must meet the tolerance. The supplied synthetic tests calibrate the evaluator, not the actual presets. Corridor role-specific masks, Everywhere CRT masks, Fracture reconstructed/rupture masks, Refraction optical checkpoints, and Spectrum/Overdrive/Mosaic per-surface masks remain to be authored. Matched final-frame pause/resume/loop and source-preserving quality/reentry remain explicitly incomplete (`media-lifecycle-fidelity`); independent playback and pool checks do not close that gate.
