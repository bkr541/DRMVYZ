# ARC ANGEL — local native preset review

ARC ANGEL is an individual Cinema 2.0 system/reference preset, not a user preset or pack. Its world consists of the supplied animated Angel, seven independently articulated bronze armillary rings, 84 emissive segments, engraved hardware, radial architectural ribs, floating embers, wrist trails, and impact waves. The shared Three scene bridge owns the renderer, camera, depth and HDR; the shared atmosphere, bloom and finish passes complete the image.

## Performance and authority

- Manual Pattern selects one of twelve authored beat-space programs; Pattern Change uses the same eleven shared trigger options as existing native presets. Both Pattern Change and Auto Performance default off; BPM Sync defaults on.
- The shared pattern resolver, clock, Mood Conductor and choreography runtime supply event identity, transient parameter drives and build/drop authority. No local analysis or independent music clock is introduced. Auto Performance never writes saved controls. A direct pattern edit interrupts automatic selection. Source replacement or seek clears transient pattern history and trails.
- Awakening and Cathedral are restrained; Divine Orbit and Communion introduce circular and paired movement; Ascension and Procession travel through the apparatus; Revelation and Incantation create build sequences; Eclipse and Dissolution reduce illumination; Judgment and Transcendence combine arm expansion with radial impact and larger gestures.
- The original GLB clip is partitioned by skeletal arm membership and body. All actions share a mixer, with independently sampled times; the source clip is not replaced by a generic loop. Reduced Motion is default. Lock Off holds the expanded character pose; lighting can continue. Flash Accents is user-owned, as are model framing and musical strength.
- The Design inspector uses Master Controls, Design, Effects, Palette. Shared quality mode reduces local lights, particles and trails. The high-poly source remains high-poly in all tiers; this is not a release-performance claim.

## Asset and release gate

Source: Angel by Just8, https://sketchfab.com/3d-models/angel-17d22525b4124088a8827d9c45a2627f. Embedded license: SKETCHFAB Standard. The repository's approved shipped-license allowlist does not include this license. The original has 1,036,253 triangles, 11 skins, 711 animation channels, and eight embedded images. Exact binary duplicate removal reduces the source from 67,667,448 to 33,438,912 bytes, without simplifying any mesh, changing animation keys, or recompressing images. It still exceeds the shipped per-file and triangle budgets, and the current shipped catalog is already near its total budget.

The patch supplies the deduplicated model at ignored `.asset-sources/arc-angel/angel.glb`. Do not force-add this source to Git, move it to public, or distribute it to other users. Vite serves only the exact local review URL to loopback clients, never in production builds. The native catalog makes ARC ANGEL available in development, or when an approved production asset with ID `cinema2-arc-angel` is registered. No shipped asset governance, license allowlist, or budget is changed. Production promotion requires appropriate redistribution rights, an approved optimized asset preserving node names and animation, manifest/pipeline registration, and visual/GPU acceptance. No database migration is needed.

## Visual acceptance (not yet completed)

Run `npm run electron:dev` on the local machine. Select React → Cinema 2.0 → ARC ANGEL. Verify ten distinct arm rigs and eleven clip groups in runtime inspection; review all patterns at 16:9, portrait and ultrawide; toggle Pattern Change and each trigger, Auto Performance, BPM Sync, Motion Safety and Flash Accents; check pause, seek, track change, silence, drop, and preset switching; verify recording/casting and GPU memory/performance on target hardware. Compare the result with the SERAPH concept reference, especially selective lighting, dark negative space, ring depth, texture fidelity and silhouette. Release only after those checks and asset approval.
