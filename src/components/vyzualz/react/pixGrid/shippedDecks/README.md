# Shipped PixGrid Decks

Each `*.json` file here is one Deck that ships with the app as a built-in PixGrid preset. Its images live in `public/pixgrid-decks/<slug>/`.

Do not write these by hand. Build the Deck in Preset Manager (Custom Workflow), then use **Export for shipping…** (development builds only) and choose the repository root: it writes this manifest and the resized images together.
