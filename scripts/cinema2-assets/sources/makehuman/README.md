# MakeHuman sources for HUM:N

The HUM:N figure (`scripts/cinema2-assets/generate-humn-figure.mjs`) is built from the MakeHuman hm08 base mesh, its default skeleton and its
default skin weights, all released by their authors as **CC0** (public domain):

| File | Upstream |
|---|---|
| `base.obj.gz` | https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj |
| `default.mhskel.gz` | https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/rigs/default.mhskel |
| `default_weights.mhw.gz` | https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/rigs/default_weights.mhw |

Copyright holders at the CC0 release: Data Collection AB, Joel Palmius, Jonas Hauquier. The files are gzipped unchanged.
