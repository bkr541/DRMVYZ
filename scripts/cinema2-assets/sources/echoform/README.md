# Echoform source artwork

These SVGs were supplied by the user for the Cinema 2.0 Echoform preset.

- `goonz-true-vector-master.svg` is the canonical render source. Preserve its bulldog-with-headphones silhouette, internal artwork, and original black, silver, gray, and cyan palette.
- `goonz-true-vector-coordinate-guide.svg` is a placement reference only. Its guide marks, labels, coordinates, and background are not render content.

Echoform treats the master as a flat layered figure: displaced planes create shallow 3D turns while a procedural point/topology field reconstructs and dissolves the artwork. The reference video informs the formation rhythm and visual texture, but its face, UI overlays, and captured background are intentionally excluded.
