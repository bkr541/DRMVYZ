Background-removal model attribution
====================================

This directory contains u2netp.onnx, a compact U²-Net model used locally by
the Media Manager's Remove Background transform.

Original U²-Net project and trained model:
  https://github.com/xuebinqin/U-2-Net

  Licensed under the Apache License 2.0.

ONNX-converted model distribution:
  https://github.com/danielgatis/rembg
  Copyright (c) 2020 Daniel Gatis
  Licensed under the MIT License.

Source URL:
  https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2netp.onnx

MD5:
  8e83ca70e441ab06c318d82300c84806

The model is bundled with the application. Image processing does not upload
the selected image to an external background-removal service.
